06 · Decisions that shape the UI

Hard rules from DESIGN.md + the six terminal motifs from DESIGN_TERMINAL.md. These are law for every screen.

Hard rules

  • Token-only colour. Every fill, text and border flows through HSL tokens in web/src/index.css, consumed via semantic classes. No raw palette hex in components; no new hues.
  • One accent. Primary red 0 100% 44% is the only brand accent — active state, emphasis, key datum, live pulse. Categorical data uses only the sanctioned ramps: --fastest-lap, --gain/--loss, --position-*, --status-*, --weather-*.
  • Team colour is identity only — thin left bar, dot or chart line, inline-style only, sourced from @/constants/f1Colors. Never a surface fill, never a Tailwind utility.
  • Component API is additive-optional. No renames, removals or new required props (e.g. F1Card scope?: boolean, default false). Pure class-only changes preferred.
  • Page structure is fixed: pageShell > pageStack + animate-fade-in > PageHeader, then F1Card sections; loading/empty/error route through F1Skeleton / F1EmptyState / F1ErrorState; charts through F1ChartContainer.
  • Logo is locked (see §01). Tokens are frozen (see §02) — tightening fixes component usage of tokens, never token values.

Terminal motifs — every screen shows at least two

  • 1 · Hairline instrument grid — rows split by border-border hairlines (.hairline-grid), not whitespace gaps. Tables read like a timing screen.
  • 2 · Mono numerics everywhere — every lap, gap, delta, speed, position, points, % and count is font-mono tabular-nums (.timing). Strongest terminal signal.
  • 3 · Instrument labels — micro eyebrows (.instrument-label), value below in mono. Label/value pairs, not sentences.
  • 4 · Corner-tick framing — hero/feature panels carry HUD corner ticks (.scope-frame, enabled via <F1Card scope>). Signature, not wallpaper.
  • 5 · Scope charts — dark plot, hairline grid, mono ticks, area fade + series glow, crosshair tooltip in dark glass (see §05).
  • 6 · Machined depth + restrained glow — shadow-card elevation; shadow-glow reserved for interactive/live emphasis.

Direction for the hero / social preview (Task 3 reuses this)

  • Badge: flat-square mono badges on dark carbon — red wash for the live/lead badge, hairline-bordered status tokens for the rest (see §04 chips).
  • Tagline: “Timing, telemetry, charts & standings.” — secondary copy in text-muted-foreground, never over the mark.
  • Red/carbon: deep-carbon field (240 8% 3.5%) with one red accent (0 100% 44%); big mono numeral + red accent must read at thumbnail size, no hairline-only detail.
