F1 DataStop — Technical Documentation

Formula 1 data analysis platform: React 18 + TypeScript + Vite frontend, Supabase Postgres warehouse with an f1-proxy edge function, Python ingestion/chart pipeline on GitHub Actions cron, Cloudflare R2 CDN. Every page renders anonymously — no login.

Architecture & pipeline mapMonorepo layout, data flow, session codes, CI job table. Backend & warehouseFresh-Supabase bootstrap, canonical f1_* schema, sync state, cutover flag. Data sources & CDNJolpica, OpenF1, FastF1 authority rules and the R2 object layout. API & embed contractsf1-proxy usage, Vercel rewrites, iframe widget endpoints and params. Runbooks & operationsCron schedules, chart pipeline, request queues, secrets inventory.

Quick start

git clone https://github.com/ibrahimroshdy/f1datastop.git
cd f1datastop
npm install --prefix web
cp .env.example web/.env.local   # set VITE_SUPABASE_URL + VITE_SUPABASE_PUBLISHABLE_KEY
npm run dev                      # http://localhost:8080

Checks before a PR

npm run typecheck && npm run lint && npm run test && npm run build
python -m compileall -q analysis   # python smoke (CI does this too)
