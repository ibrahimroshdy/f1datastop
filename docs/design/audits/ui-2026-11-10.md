# UI audit, 2026-11-10

Run before any design work for the F1 DataStop design release, on `main` at `7730106`,
against live data (CDN, 2026 season, round 20 of 23). Decisions it leads to are in
[`../decisions.md`](../decisions.md).

## What was checked

| Check | Coverage | How |
|---|---|---|
| Every route in the app layout | 12 routes: `/`, `/calendar`, `/standings`, `/race-analysis`, `/pit-wall`, `/drivers`, `/drivers/antonelli`, `/constructors`, `/teams/mercedes`, `/circuits/albert_park`, `/privacy`, a 404 | Playwright at 320, 375, 768 and 1280 px, dark and light: 96 screenshots, plus a DOM pass per page for sideways scroll, text cut with an ellipsis, text under 12 px, middle dots, native `<select>`, `<h1>` count |
| Source | `web/src` | grep inventory of components, themes, charts, rule breaks |
| Brand assets | `logo.svg`, `web/public/`, `web/index.html`, manifest, `docs/src/styles/brand.css`, README | read by hand |

Not covered: `/race-analysis/:year/:round` and the embeds (no link to a round was on the
index page at audit time), tabs inside pages, dialogs, keyboard walk, axe.

## Against the owner's rules

| Rule | Found | Worst places |
|---|---|---|
| Phones never truncate | **97 cut names at 320 px** across 6 routes (home 14, calendar 27, drivers 37, driver page 21); 46 `truncate` classes in 28 files | Drivers list "Andr…", "Max …"; calendar "Australia…", "Chine…"; standings card "Andrea …"; the driver page `<h1>` is `truncate` |
| No middle dots | 64 in strings or JSX, 42 files; rendered: home 12, calendar 20, drivers 25, constructors 26 | `raceDetailUtils.ts:46` date format, `RaceDetailDialog.tsx:94`, calendar list and grid, telemetry panels |
| No gauge bars on rows | 7 list or table surfaces | standings rows on home (10% team-colour fill scaled to the leader), `ConstructorStandingsCard`, `CombinedStandingsTab`, pit stop table, overtakes, circuit wins, Season Overview progress bar |
| No native browser UI | 2 `<select>` (`SeasonSankeyChart.tsx:324`, `:342`), 2 `alert()` (dev-only `ClarityStatus`) | |
| Lists: search, filter, group, pagination in the URL | **none complete** | Drivers and Constructors keep search and season in `useState`; Calendar has `?year` and `?view` but no search; Standings has `?tab` only, season fixed |
| Grey text on black | dark `--muted-foreground` is `240 6% 64%` on `240 8% 3.5%`, used for most secondary text | every page |
| Glass | `dark-glass` is a third theme with blur and red glows | D9 asks the owner |

## Off-brand and inconsistent

| What | Today |
|---|---|
| The red | `--primary` `hsl(0 100% 44%)` (#E00000), Tailwind `--color-f1-red` #E10600, manifest `theme_color` #E10600, docs link red lighter again. Three reds, and it is also F1's own red, so the brand reads as the sport, not the product |
| `theme-color` | four values: `index.html` #000/#fff, `ThemeContext` #0a0a0f/#fafafa at runtime, manifest #E10600, docs #08080a |
| Logo | a red radial-gradient roundel with a grey band and four white strokes; reads as a red dot at 16 px, the strokes vanish; no lockup component, three `<img>` uses at three sizes |
| Status colours | live red, completed green, upcoming blue, cancelled grey; red also means "loss" and is the brand and the primary button, so one colour has four jobs |
| Cards | `F1Card` plus base `Card` plus `premium-card`, `race-card`, `glass-*` utilities; the standings card on home nests a card in a card |
| Uppercase micro-labels | `instrument-label` (12 px caps, 0.14 em) and 9–10 px caps sidebar labels everywhere, read as noise on a phone |
| Old design board | `f1datastop-design-board.html` documents the current kit ("Logo use, final, do not redesign"); `scripts/check-design-board.mjs` checks it but no CI job runs it |

## What works and stays

- Team and driver colours from `constants/f1Colors.ts`, purple for fastest, tyre compound colours.
- Geist Mono with tabular figures for timing.
- `F1ChartContainer` and the F1 state components as the one way to show loading, empty and error.
- `pageShell` widths, one `<h1>` on 11 of 12 routes, the spoiler shield.
- Every page renders anonymously.
