F1 DataStop

F1 DataStop is a free, open-source Formula 1 site: standings, race results, lap and position analysis, a race calendar, telemetry charts and embeddable widgets. Every page works without an account.

These pages are the full documentation. The README on GitHub is only a short introduction.

Getting startedRun the site on your own computer, and the checks to run before a pull request. How it worksWhere the data comes from and the order the site looks for it. BackendThe database, migrations and server functions. Data and CDNData sources, who is trusted for what, and where files are stored. Scheduled jobsEvery automatic job, when it runs and what it does. API and embedsPut standings tables on your own site. ReleasesHow version numbers and release notes are made. RunbooksDay-to-day operations and what to do when something breaks.

What is in the project

  • web/: the website (React, TypeScript, Vite).
  • supabase/: database migrations and the server functions.
  • analysis/: Python scripts that collect data and draw charts.
  • api/: a small Vercel function that builds social preview images.
  • docs/: this site, plain HTML and CSS.
  • .github/workflows/: the automatic checks, jobs and releases.

Where to start

  • Want to run it or change it: Getting started, then the contributing guide.
  • Want to know why a number or chart looks the way it does: Data and CDN.
  • Something stopped updating: Runbooks.
  • Want standings on your own site: API and embeds.
