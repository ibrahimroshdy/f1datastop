Getting started

Run it on your computer

You need Node.js and a free Supabase project. The site does not need the Python scripts to run.

What you need

  • Node.js 20 or newer (22 is recommended) and npm.
  • A Supabase project. The site reads the cached data and the database through it.
  • Optional: the Supabase command line tool, if you work on server functions or migrations.
  • Optional: Python 3.11 and a virtual environment, if you work on the scripts in analysis/.

Install and start

git clone https://github.com/ibrahimroshdy/f1datastop.git
cd f1datastop
npm install --prefix web
cp .env.example web/.env.local

Open web/.env.local and fill in the three Supabase values from your project's dashboard (Project Settings, then API). Then start the site:

npm run dev

Open http://localhost:8080.

Settings (environment variables)

All settings are in .env.example. They all start with VITE_ and are read when the site is built. Anything optional is switched off when its value is empty.

SettingNeeded?What it does
VITE_SUPABASE_URLYesAddress of your Supabase project.
VITE_SUPABASE_PUBLISHABLE_KEYYesThe public (anon) key. It is safe in the browser because the database only allows reading. Never put the service-role key here.
VITE_SUPABASE_PROJECT_IDYesYour project's short id.
VITE_F1_PROXY_ENABLEDNotrue sends requests for Jolpica and OpenF1 data through the f1-proxy server function, which caches them. Default false.
VITE_ERGAST_BASE, VITE_OPENF1_BASENoSame-site addresses (for example /api/ergast) used on Vercel to avoid cross-site errors. They are commented out by default.
VITE_DB_SERVING_ENABLEDNotrue reads schedule, results and similar data from our own copy (CDN files, then the database) for recent seasons, and falls back to the proxy if something is missing. Default false.
VITE_GA_MEASUREMENT_IDNoGoogle Analytics 4 id. Empty means no analytics script.
VITE_CLARITY_PROJECT_IDNoMicrosoft Clarity project id. Empty means off.
VITE_ADSENSE_CLIENT_ID and the three VITE_ADSENSE_SLOT_* valuesNoGoogle AdSense. Empty means no ads script and no ad slots.

Supabase also provides SUPABASE_URL, SUPABASE_ANON_KEY and SUPABASE_SERVICE_ROLE_KEY to server functions by itself. Do not set those in your .env file.

Commands

Run these from the top folder of the project.

CommandWhat it does
npm run devStarts the site at port 8080.
npm run buildBuilds the site into web/dist.
npm run typecheckChecks the TypeScript types.
npm run lintChecks code style. Zero errors are required.
npm run testRuns the unit tests.

Before you open a pull request

npm run typecheck && npm run lint && npm run test && npm run build

If you changed anything in analysis/, also run:

python -m compileall -q analysis
cd analysis && python -m unittest discover -s tests

If you changed a schedule or a workflow, run python .github/scripts/check_schedules.py (it needs the pyyaml package). The automatic checks on GitHub run all of these. Use a conventional pull request title, such as feat(web): add a tyre chart, because it decides the next version number.
